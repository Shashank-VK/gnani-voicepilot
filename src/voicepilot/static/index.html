Microphone Permissions & Troubleshooting Guide

1. Chrome & Edge

Click the 🔒 icon next to the address bar → ensure Microphone is set to Allow. Refresh the page.

2. Safari / iOS

Tap aA in the address bar → Website Settings → set Microphone to Allow.

3. Meet, Zoom, or Teams Contention

If another active call (Google Meet, Zoom, Webex) is holding exclusive access to your microphone, mute or leave that tab so the browser can acquire the audio stream.

4. Offline / No Mic Setup

You can click any of the Example Prompts to execute clean synthesized audio turns without needing a physical microphone.
